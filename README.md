# Wishbone-Chicken-Website
This is a website for the local business of WishBone Chicken.

This website is the first DEMO version for WishBone Chicken, for my own business Lucan Cowell's Web Designs. I aim to show this DEMO version to the owners of WishBone Chicken and if they like what they see, I hope to move further in the development stage and create a fully functional website.

However, if WishBone Chicken decides that they do not wish to use my website, this still benefits me as creating this project taught me a lot of useful skills that allowed me to improve my own understanding of programming as well as website design to match the business.

In this DEMO version, the website features an aesthetically pleasing visual design that matches the overall theme of WishBone Chicken. This website also features a functional menu sorting systems that sorts the menu based off the sort of meal the user is searching for. In future versions of this sorting system, there will be a larger quantity of items, that will be specific to the businesses exact menu and prices.

The location is also seen through the use of an iframe from google maps.

At the bottom of the DEMO page, there is the contact section where the users will be able to get in contact with the business for any queries that are not answered through the website.

This project aims to set the standard for the LucanWebDesign's business which means that this first project will be the one that showcases to other potential clients what I am capable of and how it can benefit their business.

For the finished result of this webiste, the product selection will be that of the WishBone Chicken selection, as well as pricing and deals to be real and easily updatable depending on the business' plan. I will also aim to include a section which may also be added to the demo website, a "meet the owners" section where the users will get to see the story of wishbone chicken, as well as information about the owners.
